## 7. SECURITY AUDIT

* **Authentication & Password Protection:** Password di-hash menggunakan `BCrypt` (Salt 10). Refresh Token disimpan dalam bentuk BCrypt Hash (`refresh_token_hash`).
* **Presigned S3 Direct Upload (OOM Protection):** Penanganan upload file > 10MB langsung dari browser client ke AWS S3 membypass memori server Node.js.
* **SQL Injection & XSS Protection:** Parameterized queries TypeORM & NestJS `ValidationPipe({ whitelist: true })`.
* **Race Condition Protection:** Tangkapan exception `OptimisticLockVersionMismatchError` di `FinanceService` mencegah pembayaran ganda (*Double Payment Race Attack*).
